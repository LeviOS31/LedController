# LED Control app

this simple .net winforms app is made to control your external LED controllers that can be controlled from WIFI.

## Prerequisites
- LED controller should be on the same LAN as the computer
- LED controller is the SP108E

## Functions
- turn the LEDs on or off.
- change the color of the LEDs.
- LEDs turns off when app gets closed in system tray.
- Change the IP of the LED controller
- Change the Port of the LED controller.(probably not necessary)
- option to turn on/off start on startup
- will turn off LEDs when PC is shutdown if app is still running in the background
